# Assetstruktur

- `brand/legacy/` enthält Kopien der vorhandenen SVG-Markenstudien.
- `brand/source/` enthält die vorhandene Logo-Vorlage als Referenz.
- `images/hero/` enthält vorhandene Hero-/Detailkandidaten, noch keine finale
  Hero-Freigabe.
- `images/portraits/` enthält aus dem Legacy-HTML extrahierte Portraitkopien.
- `images/references/` enthält Astro-zugängliche Kopien der vorhandenen
  WebP-Derivate.

Die ursprünglichen Dateien unter `fotos/`, `marke/` und im Repository-Stamm
bleiben unverändert erhalten und sind weiterhin Source of Truth.
