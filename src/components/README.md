# Komponentenstruktur

In Phase 1 werden bewusst noch keine sichtbaren Website-Komponenten angelegt.

Vorgesehene Bereiche für die folgenden Phasen:

- `site/` – Header, Navigation, Footer und globale Conversion-Elemente
- `home/` – ausschließlich seitenspezifische Sektionen der Startseite
- `references/` – Komponenten der späteren Referenzseite
- `ui/` – kleine, projektindividuelle Primitives und Varianten

Keine Komponentenbibliothek und keine generischen Card-Systeme einführen.
