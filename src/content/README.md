# Strukturierte Inhalte

- `references/` enthält die sieben echten Referenzfälle.
- `legal/` enthält die wortgleich aus dem Legacy-Stand migrierten Rechtstexte.

Fehlende Reviews, Zertifikate und Standortinhalte werden nicht als leere
Content-Einträge oder erfundene Platzhalter angelegt. Ihr Status steht im
Content-Ledger und in den zentralen Datenmodulen.
